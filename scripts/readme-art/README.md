# README artwork

The SVG files in `docs/art/` are generated by these scripts, so a change to their text or layout is an edit here followed by a rebuild. All lettering is turned into outlines, because GitHub shows README SVGs as plain images that cannot load web fonts.

You need Python 3 and fontTools.

```sh
pip install fonttools
sh scripts/readme-art/fetch-fonts.sh
python3 scripts/readme-art/build.py
```

The fonts land in `scripts/readme-art/fonts/`, which is ignored by git. Set `FONT_DIR` to use fonts from somewhere else, or `OUT_DIR` to write the SVGs somewhere else.

| File | What it makes |
|---|---|
| `lib.py` | The palette, text to outlines, and the site's shapes (skewed blocks, cut-corner panels, the EN/NL switch). |
| `banner.py` | `banner.svg`, the hero in miniature. |
| `pieces.py` | The nine section plates, the loadout cards, the stack panel, the footer and the link buttons. |
| `build.py` | Runs both. |

The colours and shapes follow `src/assets/style.css`, so when the site's palette changes, change `lib.py` to match.
